Wire-compatible with 0.36.x: a new client streams from an old host and the other way round, so you can update one side at a time — except on Windows, where the host and its display driver update together.

- **A rebuilt app for iPhone, iPad and Mac.** Hosts and Library get their own tabs, a host card shows two lines with a page for the rest, and the Mac gets a sidebar and a window per host.
- **Sort your library by what you played last or most.**
- **The same stats on every client.** The overlay shows the figures Moonlight's overlay shows, measured the same way on Windows, Linux, Android, iPhone, iPad, Mac and Apple TV. **Advanced statistics** brings back the full capture-to-screen view.
- **A lost packet heals cleanly more often.** HEVC from an NVIDIA host no longer leaves a grey smear that drifts with motion, repairs from Intel hosts now repair, and AV1 from an NVIDIA host heals exactly.
- **A host saved at its Tailscale address keeps it.** Coming home no longer swaps it for the LAN address, so the host is still there on mobile data.
- **Windows hosts stream 5.1 and 7.1** without you changing Windows' speaker setup.
- **Steam Controller 2 on Apple TV**, over Bluetooth. Behind a Puck on a Linux host it no longer drops into lizard mode.
- **Windows clients stop holding frames back.** A queue that could add 45–65 ms on a 60 Hz panel is gone.

## Before you update

- **Windows: run the installer.** It updates the host and the display driver together; expect a brief black screen while the driver reloads. A 0.36 driver under a 0.37 host refuses to stream and says "driver outdated".
- **Bazzite: restart once after this update.** From now on an update restarts the host and its console for you, but the step from 0.36 still runs the old updater. Run `systemctl --user restart punktfunk-web punktfunk-host` afterwards, or the console fails to load its pages.
- **Profiles are now called presets.** Your saved ones carry over, and links, shortcuts and commands that say profile still work.
- **The stats overlay starts on the shorter view.** Turn on **Advanced statistics** in the client's settings to get the stage breakdown back.

## New

### iPhone, iPad and Mac

- **Hosts and Library are two tabs** on iPhone and iPad. The Library is a list of sections — Desktops, Recently Played, Favorites, Launchers and Games — that Customize reorders or switches off. A long-press marks a favorite, search filters every row, and chips at the top pick the host. On an iPad the tab bar can turn into a sidebar.
- **Host cards are two lines:** the name, then the status and the host's preset, with a star on the default host. Everything else moves to a host page — presets, connection, pairing, power, logs and removal, each with a line of explanation — which opens as a sheet of sections on an iPad. The card's menu keeps five everyday actions, and Forget and Remove ask first.
- **Title details.** A long-press on a title leads with Play, or Resume when it is running, and Details shows the cover, store, credits, genres and your play record.
- **On a Mac, a sidebar and a window per host.** The sidebar holds Hosts and the Library, and ⌘1 and ⌘2 switch between them. A card's ⓘ opens that host's page in its own window. Text in forms, popovers and sheets is sized for the Mac.
- **The speed test is a page with a live chart** of the test as it runs, with the average and the recommended bitrate drawn across it. Apply says what it changed. On Apple TV too.

### Library and presets

- **Sort by Recent or Most played**, from the play time the host already records, in the console view, the Linux and Windows apps and the Apple apps. A library from an older host sorts as before.
- **Profiles are now presets** in every app, link and command. Saved presets carry over, and an older app on another device keeps seeing them. Links take `preset=` and still read `profile=`; `punktfunk presets` replaces `punktfunk profiles`, which still works.

### Statistics

- **One overlay, one set of numbers.** Every client measures and labels its stats the same way, so a figure on a Mac means what it means on Android. By default the overlay shows the figures Moonlight's overlay shows, as averages.
- **Advanced statistics**, a new switch in each client's settings, shows capture to screen as a median and a slow-frame figure, and every stage between. It belongs to the device, so a preset never changes it.
- **The console's Performance page reads in milliseconds**, against a line at one frame for the stream's rate. It charts the round trip, and a counter the host can't see leaves a gap instead of a flat zero.
- **Windows host recordings show where the time goes:** waiting for a free buffer, encoding, and the hand-off to the host, instead of one lump. Every host also records what sealing and sending each frame costs.

### Apple TV

- **Steam Controller 2 over Bluetooth.** Turn on capture in settings and Steam Input, the trackpads, gyro and rumble reach the host, instead of a generic pad in lizard mode. It starts off because turning it on can ask for Bluetooth access.
- **The Liquid Glass icon**, the look every other Apple platform already had, with its layers moving on focus.

### Audio

- **5.1 in the layout LG TVs decode natively.** The host can send surround the way the TV's own decoder expects, so the webOS app passes it to a receiver without re-encoding every packet.

### Docs

- **Troubleshooting is five shorter pages:** startup, connecting, the stream, input and audio. A new guide to [reporting an issue](https://docs.punktfunk.unom.io/docs/report-an-issue) builds one file with every log a report needs, and the [stats page](https://docs.punktfunk.unom.io/docs/stats) leads with the view Moonlight users know. ## Improved

- **Windows clients on integrated graphics:** the D3D11 decode path no longer copies every frame an extra time, and converts colour on the GPU the way the Vulkan path does. That helps 4K HDR on laptops such as those with a Radeon 780M.
- **Windows clients on older AMD drivers** get one warning when an HDR stream might paint green on Vulkan. Updating to Adrenalin 25.9.1 or later fixes it; nothing is switched for you.
- **Linux and Windows clients** skip a decoder their graphics can't run before the stream starts, instead of after the first frame.

## Fixed

- **Every client:** a host saved at a Tailscale address keeps it. The saved address used to follow whichever address answered, so turning the VPN off at home swapped it for the LAN one. A host that stops answering where it was saved is looked for at its live address and the last three it used.
- **Dual-boot hosts:** both installs of one box stay apart when you tap a card, add a host, pair or open a link. A tap on one no longer dials the other and fails, and a launch no longer takes the other install's preset or clipboard choice.
- **Lost packets:** HEVC from an NVIDIA host no longer smears grey after a loss during a repair, as reported on 0.36. The picture unfreezes only once the repair has reached every damaged row, instead of one cycle early. AV1 from an NVIDIA host heals exactly instead of carrying damage until a keyframe.
- **Linux hosts on Intel graphics:** the gradual repair after a loss refreshes the picture. It used to refresh nothing, so the damage stayed until a keyframe.
- **Windows clients on AMD graphics:** HEVC from an NVIDIA host no longer decodes wrong until the next keyframe when the repair reaches back past more than one frame.
- **Windows clients:** a PC whose graphics can't decode HEVC no longer starts every stream twice.
- **Linux and Windows clients:** frame pacing reads the panel's real refresh again, so the host lines frames up with your screen; a refresh change mid-stream re-learns it. Switching to HDR no longer crashes when the display layout changes at the same moment.
- **Android:** a mouse's side button that Android turns into Back goes to the host, including on Samsung's One UI 8, where that mapping can't be changed; the Back gesture still opens the quick-action ring. Leaving a stream started from the console no longer flashes the touch interface while the controller comes back. A Steam Controller 2 behind a Puck no longer goes dead for a moment every three seconds, and its rumble no longer replays stale levels after a stall.
- **iPhone and iPad:** the pairing prompt is a readable alert on iOS 26, and the trust card fits a phone held sideways.
- **Apple TV:** a host card's Edit opens the host editor instead of closing the menu.
- **Steam Controller 2 on a Linux host:** haptics and mode changes no longer wait one to three seconds, and the pad no longer drops into lizard mode. Steam no longer offers a firmware update for a pad behind a Puck on every stream.
- **Hosts next to Sunshine:** Linux setup no longer turns on Moonlight compatibility, since both hosts want the same ports; turning it on yourself still works, with a warning. Omarchy and SteamOS setup move the console's port off Sunshine's before handing off, and Omarchy's firewall opens the moved port, so the library loads. Omarchy setup applies the host options you chose again, and a fresh Windows install gets its default host settings.
- **Windows host:** a 5.1 or 7.1 session carries surround without setting Windows' speakers by hand; the host sets its own virtual speakers and leaves your real hardware alone. When Sunshine holds port 47990, the firewall now opens 47991, where Punktfunk moved, so the library loads on clients again; upgrading heals an affected box. A display driver that can't start its graphics device reloads once instead of failing every session until a reboot.
- **Gamescope hosts:** on Arch, Debian and Fedora, a host without the distro's own gamescope no longer streams a black screen; our gamescope package now brings the helper it starts every session through. A kept gamescope that crashed is no longer handed to the next client. One failed HDR attempt no longer keeps every later session in SDR until the host restarts.
- **Bazzite:** an update restarts the host and its console, so the console no longer fails with "Failed to fetch dynamically imported module" until you restart it by hand.
